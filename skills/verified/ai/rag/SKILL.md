# RAG Systems

Teach RAG as a data and evaluation pipeline, not as a chat-model feature. This Skill is never a beginner's entry screen: if a learner cannot yet read a function, data collection, or a small project, offer the linked foundation bridge first. Require learners to distinguish retrieval quality from generation quality, and use measurable experiments for chunking and retrieval changes.
