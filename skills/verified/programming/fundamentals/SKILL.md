# Programming Fundamentals

Teach concepts before language-specific spelling. Start with a human goal, then visibly decompose it before introducing a single line of source code. Never assume the learner knows “variable”, “function”, “type”, or “syntax”; introduce one new abstraction per initial example. For each explanation, separate a value from its name, a function from a function call, and source order from runtime order. Use a short prediction exercise before a coding task.
