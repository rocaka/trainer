# 值与标签

```js
let name = "小明"
```

这行代码把要记住的文字“**小明**”放在右边，并给它一个叫 **name** 的标签。`let` 表示“现在新建这个标签”。

先记住一个关键点：`name` 不是小明本人；它只是程序以后找到“小明”这个文字的方式。

## 小实验

如果要登记“小红”，只把右边的 `"小明"` 改成 `"小红"`。标签 `name` 仍然可以继续表示“这位同学的名字”。
