# 代码是什么？

先不要把代码当成一门外语。它只是把“我想让电脑做什么”拆成电脑不会误会的小步骤。

例如，人话是：“请记住这位同学叫小明。”

程序需要明确两件事：要记住的内容是“小明”；以后要怎样找到它。下一课会把这个“以后怎样找到它”的方法叫作标签。

## 预测
