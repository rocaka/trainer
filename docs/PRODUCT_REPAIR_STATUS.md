# 产品链路修复记录

## OpenCode 额度错误识别（2026-09-16）

- 真实连接诊断确认 OpenCode 可用额度不足：返回 HTTP 401、text/plain，正文为 CreditsError。此前仅按状态码误判为密钥失效。
- 统一传输层限量读取错误正文，只映射已知额度错误类型，不显示原始错误文本、账户链接或密钥；未知响应继续使用安全的状态码提示。
- 教练请求遇到额度、鉴权及其他明确配置错误立即停止自动重试；用户可在补充额度或调整配置后手动重试。
- 14 项传输层测试通过。真实教练恢复仍受服务商账户可用额度限制，不宣称已通过真实生成验收。

## GitHub 项目语言同步与个人主页入口（2026-09-16）

- Device Flow 成功刷新后，将贡献日历、贡献计数和最多 100 个本人公开仓库的语言字节聚合写入本机学习档案；不经过 Trainer Gateway 保存 OAuth Token，也不保存源码、仓库名、文件路径或提交内容。

- 选中 Skill 后按教学资产生成 3–8 节专属课程，异步任务显示等待/失败/重试。
