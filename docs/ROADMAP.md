# Delivery Roadmap

## Phase 0 — Foundation (current)

- Product, pedagogy, safety, and architecture specifications.
- Native workbench prototype.
- Initial versioned Skill catalogue.

## Phase 1 — Code understanding loop

- Import focused snippets and editor selections.
- Parse language syntax and map to concept graph.
- Local learner model with transparent mastery evidence.
- Deterministic JavaScript/Python micro-experiments.

## Phase 2 — Project companion

- VS Code extension and permission centre.
- Consent-based project indexing, diagnostics, and source navigation.
- Explain diffs, tests, stack traces, and data flow.

## Phase 3 — Domain laboratories

- EVM test-only simulations, Solidity security labs, and Foundry integration.
- RAG dataset/retrieval/evaluation labs.
- Database transactions and Web request-path simulations.

## Phase 4 — Curriculum evolution

- Skill authoring/validation pipeline.
- Source provenance, Git-backed versioning, and review workflow.
- Personal drafts with explicit promotion gate.

## Definition of done for each feature

A feature is done only when it has a user learning outcome, interaction feedback, permission boundary, telemetry/success event, accessibility pass, and test/verification evidence.
