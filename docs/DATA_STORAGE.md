# 本地档案与持久化

## 卸载与备份

仅删除 Trainer.app 不会由程序主动删除 Application Support/Trainer；重新安装后读取同一路径。第三方卸载器、手动清理数据目录、账号目录丢失或换电脑不在此保证内。

学习档案提供“导出本地备份 ZIP”。SQLite 使用 backup API 生成一致快照，课程、版本、候选、计划、任务和头像一并打包；排除 API Key、系统偏好和符号链接目标。文件集合备份期间应暂停生成、审批和修改操作，避免跨文件状态变化。备份包含私密项目内容，不应公开分享。建议另存到外置盘等独立位置。

学习档案提供“从备份恢复”：先校验 ZIP 路径、大小和数据库，再确认恢复。生成任务运行时拒绝恢复；原数据移动到 restore-history 下保留，安装失败会回滚。恢复的未完成任务标记为暂停，不自动产生新 API 请求。云登录和跨设备同步未上线。

默认数据目录：`~/Library/Application Support/Trainer/`。开发和测试可通过 `TRAINER_DATA_DIR` 指向隔离目录。

- `trainer-learning.sqlite3`：本机个人资料（昵称、简介、头像）与带时间戳、课程标识、类型的学习凭据。SQLite 事务提交后持久保存。等级和成就由记录计算，不独立维护容易失去同步的计数器。
- `skills/`：课程 Skill、源项目教学快照、版本关系及可恢复的回收区。
- `pending-approvals/`：待人工审批的候选。
- `learning-plans/`：按内容和规则版本区分的课程缓存、分批检查点及 Markdown 导出。
- `job-history/`：任务状态和可恢复的课程规划请求。重启续跑可能产生 API 费用。
- SQLite course_progress：课程位置；已记录课数从 evidence 重建，随备份恢复。macOS UserDefaults 保留窗口偏好与旧版位置兼容缓存。
- macOS Keychain：API 密钥；个人档案数据库不保存 API 密钥。
- `avatars/`：用户选择的本地头像，中心裁切为 256×256 PNG。数据库仅保存 UUID 引用，原图不发送给模型；未保存的头像预览文件也保留在此目录，备份时可一并保留。

语言雷达与练习类型分离。“本课能力评估”将用户主动提交的凭据按本课目标送给已配置 DeepSeek；原文引用无法定位时拒绝分数。assessments 表保存课堂估计及反馈，同课同类型重评替换旧估计。雷达取已有课堂估计的均值，明确标为 AI 课堂评估；它不证明该语言整体能力，也不宣称代码已执行。未评估的语言仍显示待评估。

首次启动将旧应用包中的已有资产和 SQLite 复制到新目录，保留原件、不覆盖新目录已有文件。迁移完成标记防止以后重新导入已清理资产。应用更新仅替换程序，不删除上述运行数据。

在开发项目内运行的应用也会合并同项目旧开发数据库中的学习凭据，按完整记录去重，保留当前个人资料与原数据库。

备份时先退出 Trainer 并停止其 Gateway，再复制整个数据目录；同时备份 macOS 的应用偏好以保留界面位置。恢复须在 Gateway 停止时操作，并先保留当前数据备份。不应把含项目源码的备份公开上传。

当前为单机个人档案，不包含注册登录、密码、云备份、多用户隔离或跨设备同步。统计仅代表提交的练习凭据：每项首次记录 10 XP，重复记录不重复增加 XP；五维图表是记录数量，不是经验证的能力评分。
