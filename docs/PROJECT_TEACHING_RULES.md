# 项目专属教学规则

## 导入项目执行协议 · PROJECT_IMPORT_PROTOCOL_V1

当 generationMode 为 project-import，或材料明确来自导入的现有项目时应用本节。独立创建课程不应虚构现有源码；项目实战继续使用其从零构建协议。三种模式要求相同的教学深度与可检查产物，但不强制采用相同起点。

导入课程必须围绕真实项目建立五段主线：读懂 → 跑通 → 修改 → 测试 → 独立重建关键模块。不能止于目录概览与最小语法基础，也不能要求初学者一次重写整个项目。

1. 读懂：从已提供文件中选择入口和一条业务路径，展示调用、输入输出与数据流。未看到源码的关系标为待核对，不凭文件名推断成事实。
2. 跑通：明确环境假设、配置检查、用户执行的命令与预期结果。材料不足则列出待补项；不编造启动命令，不自动安装依赖、运行未知项目或访问生产服务。
3. 修改：给出小需求变更，定位已有文件/函数、解释必要前置知识，提供逐级提示及具体产物，不能只让用户复制最终代码。
4. 测试：分别设计正常、边界、失败路径，注明测试文件或用户提供报告的方式，说明通过条件。静态评审与用户运行报告分别标记，未实测不得称运行通过。
5. 独立重建：选取一个已学关键模块，在独立练习目录实现或替换，明确接口约束、行为对照与验收标准，不覆盖原项目。

每个模块必须声明：已知源码依据、未覆盖范围、前置能力、学习目标、具体文件/符号（仅限实际材料）、语言知识、读改写任务、提交材料、预期结果、验收与重试路径。所有解释按 Markdown 标题、短段落、带语言代码块和必要对比表排版。

导入候选的 exerciseMarkdown 必须使用独立二级或三级标题：读懂、跑通、修改、测试、独立重建、提交材料；validationChecklist 必须包含“验收标准”标题。每节写具体说明而不是空标题。前置材料不足时明确缺少什么以及下一步如何补充，不得编造步骤。程序只检查这些章节的存在与非空，内容正确性仍需人工审阅。

首轮有限摘要只用来规划候选，不是完整项目分析。先列“已确认 / 待核对 / 待补材料”，后续按真实源码模块展开；不得因为摘要缺失而用通用入门课程填满或宣称完整覆盖。规则标识只说明所用协议，不等于内容已经质量验收。

## 两种入口，同一质量要求

独立创建课程与项目导入共用下述教学深度、练习、验证和人工审批要求。用户的补充要求不能削弱安全、来源准确性或验证规范。

- 独立创建：从用户目标、基础与目标作品规划能力依赖和阶段成果；未知基础须明确假设并安排诊断。没有项目源码时，不得虚构已扫描的目录、函数或文件引用。用标注为“教学简化示例”的完整渐进式小项目，逐步讲解语言基础、高级语法、核心技术、测试与独立实现。
- 导入项目：先分析真实项目结构、入口、调用关系、数据流和技术栈；依据源码清单覆盖函数、语法和边界。区分实际代码与教学改写，标注未读取和待覆盖内容。
- 两者都需要学习者画像、可检验目标、前置依赖、由浅入深的模块、逐步代码讲解、常见误区、读/改/写练习、预期结果、验收标准与迁移任务。不能把详细课程压缩为标题大纲；不为增加字数重复内容。

## 教学与覆盖规范

选中的 Skill、项目材料与学习目标决定课程内容、数量和顺序。禁止为每个项目重复套用固定六课。基础知识必须在目标项目的具体例子中补齐：例如 RAG 从文档片段和检索结果认识列表与函数；订单项目从订单字段与库存变化认识变量与条件。

先给出项目目标、目录职责、入口、依赖、数据流和错误路径。再按源码模块分批展开，每批 3–8 个可验证的小课，整个项目不限制为 3–8 课。每课必须包含独立 id、具体标题、目标、语言、代码、逐步解释、观察任务、回讲题和验证标准。标题应指向实际对象与行为，而不是仅写“变量”“函数”。

分层顺序：项目全景 → 项目内语言基础/运算/类型/控制流 → 函数参数返回值/作用域/数据结构 → 异步、泛型、装饰器等源码实际出现的高级语法 → 框架、数据库、AI/区块链等核心技术 → 错误处理、测试、重构、独立实现与迁移。没有出现的技术不强行添加。

源码细讲必须解释每个函数做什么、由谁调用、输入输出、局部变量、分支、异常、副作用、依赖、边界条件和可替代实现；说明每段关键语法的含义。解释字段可使用多段 Markdown，不得压缩成一句话。练习包含预测输出、补全代码、修改需求、独立实现、测试用例与验收条件。禁止仅靠完成选择题宣称掌握。

项目快照及函数清单为覆盖依据。未读取、截断、解析失败和未讲到的内容须明示；逐文件分批生成允许断点续跑，但不能把扫描覆盖率等同于教学质量或学习掌握率。

明确区分项目原始代码与教学简化示例。只能引用输入中实际存在的文件与内容；没有源码时标明“教学简化示例”，不得声称已分析项目。不得为凑数量添加内容。多技术栈按各课实际技术分别声明，不能继承上一项目的语言。

基础桥接由缺失的前置能力决定，不是所有人的强制固定路线。课程完成只代表提交了学习证据，不等同于已掌握。切换课程不能自动把前面的课程标为已掌握。

模型生成的学习计划标记为 AI 草案；格式验证不等于内容验证。失败必须可见并允许重试，禁止用通用课程冒充项目课程。持久缓存须绑定 Skill 内容版本和规则版本。优化/审批不得静默覆盖资产。
